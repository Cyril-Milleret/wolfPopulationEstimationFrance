# 🐺 Wolf Population Size Estimation in France

This repository contains **R code and data** used to reproduce official estimates of **wolf (*Canis lupus*) population size in France** based on **non-invasive genetic sampling** and **spatial capture–recapture (SCR) models**.

The repository is organized by **winter season**, with each folder containing the data, scripts, and outputs required to reproduce the corresponding population size estimates.

Each yearly folder includes:
- Raw and processed data
- R scripts to reproduce published results

---

## ❄️ Winter 2023–2024 (2024)

Data and code to reproduce results presented in:

**Milleret, C., Duchamp, C., & Gimenez, O. (2025)**  
*Mise à jour des estimations démographiques et des effectifs de la population de loups en France lors de l’hiver 2023/2024.*  
CNRS; OFB. HAL-05016361. Available at: https://hal.science/hal-05016361/  and  at: https://www.loupfrance.fr/

**Milleret, C., Duchamp, C., Bauduin, S., Kaerle, C., Pirog, A., Queney, G., & Gimenez, O. (2025)**  
*Estimating wolf population size in France using non-invasive genetic sampling and spatial capture–recapture models.*  
arXiv (submitted). Available at: https://arxiv.org/abs/2508.12434

## 🔁 Reproducibility

All analyses are fully reproducible using the scripts and data provided in this repository. 
Large GIS layers are not provided, but source location to download them is provided. Exact coordinate locations of the detections have been replaced by the center location of the closest detector. For more information, please contact theDGPT service of the OFB. 
Sensitive personal information have been masked when present.
